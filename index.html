AI-native tools for filmmaking.

CDS Films is a founder-led studio building software for screenwriters and small production teams: turning finished films into screenplays, developing a script through to shoot preparation, and running a small studio with supervised AI agents.

See the products cdsf@cdsfilms.com

Three products, one workflow

Each tool is a separate app, built around the same idea: the screenplay is the source of truth. FTS writes standard Fountain screenplays, the format Singularity Pencil imports. 1ManABnd is the operating layer we use to run the work around them.

01

FTS

Film-to-Screenplay

Turns a film or video file into a structured screenplay in Fountain format.

  • Audio extraction, transcription and speaker diarization, aligned into lines of dialogue.
  • Scene detection and keyframes; Claude reads each scene's frames and nearby dialogue to write the scene heading and action.
  • Claude maps anonymous speakers to character names and polishes the assembled draft scene by scene.
  • Every stage is cached, so reruns skip finished work. A fully local mode runs without cloud APIs.
In development

macOS desktop app and command-line tool, used internally. Windows version in development.

02

Singularity Pencil

Screenplay-native production workspace

One script drives writing, rewriting, storyboards, breakdown and shoot planning, so a change in the screenplay reaches everything built on it.

  • Screenplay editor with full Vietnamese input; Fountain, FDX, PDF and DOCX import and export; portable .sp project files.
  • Rewrite tools (draft compare, notes, scene variations), scene storyboards and revision tracking.
  • Breakdown, plan and shoot views, including day-out-of-days and element lists, generated from the same script.
  • Optional AI assistance with the writer's own OpenAI or Anthropic API key.
Closed pilot

Web and desktop. Hosted pilot for a small group of invited testers; not publicly released. The name is provisional.

03

1ManABnd

Local-first AI-agent operating system

A desktop app that lets one person run several projects with teams of AI agents, while approving everything before it leaves the machine.

  • Each project is a tree of departments with specialised agent roles; a lead agent plans the task and delegates.
  • Agents run on Claude Code with per-role tool allowlists, run quotas, timeouts and a pause switch.
  • Every deliverable waits in an approval queue. An append-only event log records what each agent did.
  • Runs on the user's own computer: no 1ManABnd cloud server and no account with us.
Beta

macOS desktop app (v0.5 beta), in internal use by the founder.

How we use Claude

Claude is already part of our working R&D stack. FTS calls the Anthropic API for visual scene understanding and screenplay processing, and 1ManABnd runs its agent workflows on Claude Code under human supervision.

FTS · Anthropic API

Scene understanding and screenplay processing

Keyframes from every detected scene go to Claude through the Message Batches API, which returns a structured scene heading and action description. Claude then resolves speakers to character names and polishes the draft in chunks split at scene boundaries. Transcription uses Whisper; a local mode with open models exists for offline work.

1ManABnd · Claude Code

Supervised agent workflows

Agents run through Claude Code in headless mode. Each role gets only the tools it is allowed, runs inside quotas and timeouts, and hands its output to a person for approval. OpenAI Codex can be selected as an alternative engine.

Singularity Pencil · Bring your own key

Optional assistance for writers

AI is off unless the writer adds a key. Rewrite and storyboard help works with the writer's own OpenAI or Anthropic account; the screenplay stays the writer's work.
